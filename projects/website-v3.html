Overview

Website V3 is the third major iteration of my personal website. It was designed to showcase work with clarity, support concise case studies, and provide a calm digital presence that feels both modern and grounded.

The Problem

Previous versions of the site were visually busy and lacked a consistent structure for storytelling. The portfolio needed a cleaner framework that made projects easy to browse and process-focused content easy to read.

The Solution

A streamlined, responsive website built around a modular content system. The redesign emphasizes thoughtful typography, accessible navigation, and a quiet visual language so work and process take center stage.

Key Features

  • Project-focused case study pages with clear narrative flow
  • Responsive layout designed for fast loading across devices
  • Minimal interface with deliberate use of whitespace and motion
  • Consistent brand system that supports both portfolio and process

Technologies

HTML CSS JavaScript Responsive Design Static site

Challenges

Balancing a distinctive visual identity with accessibility and ease of use. Crafting a design system that can handle both short summaries and deeper project stories without feeling heavy or overly decorative.

Focus Areas

  • Clarity
  • Process
  • Personal brand
  • Calm design
