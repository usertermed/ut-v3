Child Labor Statistics

Educational Data Visualization

Visit Live Site ↗

Overview

Created for a school assignment, this project presents child labor statistics through a clean, accessible interface. The goal was to make complex information easier to understand without sacrificing clarity or respect for the subject.

The Problem

Raw statistics on sensitive topics can be dense, intimidating, or poorly presented. When data is hard to parse, it fails to educate. Accessibility and clear visual hierarchy become essential for meaningful communication.

The Solution

A focused data visualization experience that prioritizes legibility, structure, and accessibility. Charts and figures are presented with supporting context so readers can grasp both the numbers and their significance.

Key Features

  • Clear presentation of complex statistical data
  • Accessible design patterns for broader reach
  • Educational framing that supports understanding
  • Restrained visual language that keeps focus on the information

Technologies

HTML CSS JavaScript Data Visualization Accessibility

Challenges

Handling sensitive subject matter with care. Designing charts and layouts that remain readable on small screens. Ensuring the interface meets accessibility expectations while staying visually coherent.

Focus Areas

  • Data presentation
  • Education
  • Accessibility
  • Clear communication
